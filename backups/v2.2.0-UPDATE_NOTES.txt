Delivery-Man-Plugin v2.2.0 - Source Backup & Update Notes
==========================================================

Backup Created: 2026-08-19
Branch: main
Backup Type: Pre-v2.3.0 baseline

State of v2.2.0
-----------------
- Build system: Gradle 8.10.2 with com.gradleup.shadow 8.3.0
- Java target: 21
- Backend support: MongoDB, MySQL (HikariCP), SQLite
- Cache layer: Optional Redis via CachedDatabase (write-through)
- Addons: Votifier, PlaceholderAPI, MVdWPlaceholderAPI
- Custom event: DeliveryPlayerLoadEvent
- Custom logger: PluginLogger with LogLevel

Known Open Issues Scheduled for v2.3.0
----------------------------------------
- #1  HIGH   CachedDatabase performs synchronous Redis I/O on main thread during join/quit
- #2  HIGH   Race condition: rewards claimed during async loadPlayer window are overwritten
- #3  MEDIUM savePlayer's finally block removes player from cache, causing double-quit data loss
- #4  MEDIUM SQLDatabase shares single SQLite Connection across async tasks (not thread-safe)
- #5  MEDIUM RewardMenu.updateActiveMenus runs async and mutates inventories off-main-thread
- #6  MEDIUM RedisCache reads config once in constructor; reload does not re-create the cache
- #7  HIGH   AddonManager.loadAddons registers VotifierListener on every reload - vote rewards duplicated
- #8  MEDIUM DataManager.voting map never cleaned up - memory leak for disconnected players
- #9  MEDIUM DataManager.getPlayerData uses computeIfAbsent - race with async loadPlayer loses claims
- #10 MEDIUM MySQLDatabase.buildJdbcUrl - database name not URL-encoded, allows JDBC param injection
- #11 LOW    Reward constructor crashes plugin on invalid config values (valueOf without try-catch)
- #12 MEDIUM MenuListener identifies reward menu by title string - any inventory with matching title is hijacked
- #13 MEDIUM ConfigManager.reload throws on invalid DBType - partial config update leaves plugin in inconsistent state
- #14 MEDIUM PlayerListener calls savePlayer on both PlayerKickEvent and PlayerQuitEvent - double save race
- #15 MEDIUM executeCommands substitutes player name into console commands without escaping - command injection on offline-mode servers
